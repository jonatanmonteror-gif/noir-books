# Noir Books

Lector de libros EPUB para Android (móvil y tablet), con el estilo de Noir+.

- Biblioteca con portadas, "Seguir leyendo", búsqueda y orden (recientes, título, autor).
- Añadir libros desde el selector de archivos, o "Abrir con" / "Compartir" desde otra app.
- Lectura por páginas (toques en los bordes o deslizar), dos páginas en horizontal en tablet.
- Ajustes de lectura: tema (claro, sepia, oscuro, negro), letra (Original, Literata, Clásica, Inter, Atkinson), tamaño, interlineado, márgenes, justificado, guiones, brillo, volumen para pasar página.
- Índice, marcadores con el texto de la página, progreso del libro y tiempo restante del capítulo.
- Actualizaciones dentro de la app con comprobación SHA-256 y registro de errores (copiar / compartir).

Solo abre EPUB **sin DRM**.

## Instalar

APK: https://github.com/jonatanmonteror-gif/noir-books/releases/latest/download/NoirBooks.apk

GitHub Actions compila y publica una versión nueva (`v1.0.N`) con cada cambio en `main`.
